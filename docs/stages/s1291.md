# s1291: AsyncAudioPlayer tests keep their TrackFetcher alive (task #1320)

`makePlayer()` in `AsyncAudioPlayerTests.swift` created a `TrackFetcher` that
nothing held strongly once it returned: `AsyncAudioPlayer.fetcher` and
`HistoryFetcher.trackFetcher` are both weak. Track lookups then found nothing,
failing `playingQueueIsPlayingTrackThenKnownQueuedTracks()` and
`playUntilFillsTheRemainingTime()`.

A test-only subclass now retains the fetcher. The weak reference in the app code
is deliberate and unchanged.

## Verification

`scripts/exit/s1291.sh` runs the `AsyncAudioPlayerTests` filter.
