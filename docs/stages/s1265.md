# s1265: keep offline plays and skips (task #1300)

Plays and skips are written to the `pending_history` table of the client's local
SQLite store and deleted once `POST /history` succeeds. See
`docs/decisions/1255-pending-history.md`.

- `PendingHistoryQueue` appends and drains, oldest first, stopping at the first
  failure. It drains on each online play/skip, on leaving local-only mode and
  when a `Client` starts.
- `HistoryFetcher.hasPlay` / `hasSkip` include pending entries.
- DJukeboxClient has a test target; CI and the `swift-client` suite run it.

Exit check: `scripts/exit/s1265.sh`.
