# s1282: offline relaunch restores the local queue (task #1296)

`TrackFetcher.initialize(with:)` now watches the saved queue before it sets
`useLocalContentOnly`. Going offline loads the catalog synchronously, which
consumed the saved state while no queue was being watched.

Saved hashes the catalog no longer knows are dropped on restore. If the playing
track is one of them, its saved position is dropped too.

`TrackFetcher.queueType` is no longer implicitly unwrapped; it defaults to
`.local`.

player and a stub local cache. No app relaunch was tried on a device.
