# s1262: DJukeboxClient tests (task #1292)

Added the `DJukeboxClientTests` target (Swift Testing) covering duration
parsing, the `RuntimeState` on-disk format, local playing-queue operations in
`AsyncAudioPlayer` and `TrackFetcher.update(playingQueue:)`. The fakes (a
server with `hasServer` false and a silent `AudioPlayerType`) are in
`Fakes.swift`, for later tests to reuse.

The MASON `swift-client` suite now runs `swift test` instead of only building,
and so does the `DJukeboxClient` job in `.github/workflows/ci.yml`.

The one production change: `RuntimeState`'s encoding and decoding moved into
`encoded()` and `decoded(from:)`, which `save()` and `saved()` call.
