# s1294: AsyncAudioPlayer tests keep their TrackFetcher alive (task #1323)

`AsyncAudioPlayer` holds its `TrackFetcher` weakly. The `makePlayer` test helper
kept the fetcher only in a local, so it was deallocated on return, every track
lookup found nothing and `movePlayingTrack` threw `moveFailed`.
`FakeAudioPlayer.fetcherOwner` now keeps the fetcher alive for the test.
