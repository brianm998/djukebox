# s1280: unparseable track durations are unknown (task #1294)

`AudioTrack.timeInterval`, in both the client and the server copy, returns nil
unless `Duration` starts with three finite, non-negative `h:mm:ss` components.
It used to trap on an empty string, return NaN for "nan" and return 0 for other
mismatches. `timeIntervalString` is empty for nil and for values too large to
format.

## Verification

`AudioTrackTests` in `DJukeboxClient/Tests` and
`djukebox_server/Tests/AppTests` cover the inputs.
