# s1284: LocalTracks catalog lock and incremental inserts (task #1302)

The downloaded-track list and its SHA1 index sit together behind one
`OSAllocatedUnfairLock`; `downloadedTracks` and `downloadedTrackMap` return
snapshots. `keepLocal` inserts one track (`insertDownloaded`) instead of
re-sanitizing the list. `cacheSequentially` returns when there is no local
store instead of awaiting a continuation nobody resumes.
