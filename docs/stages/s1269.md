# s1269: single source of truth for the version (task 1306)

- Version: `DJukeboxCommon/Sources/DJukeboxCommon/Version.swift`, read by
  `scripts/version.sh`. See decision 1259.
- Server: `GET /version` (no auth) returns `{name, version}`; logged at startup.
- Clients: `VersionLabel` shows the app version and the server's, in the macOS
  header bar, the iOS connection screen and the iOS playing tab.
- Check: `scripts/exit/s1269.sh`.
