# s1278: release workflow around `release_darwin.sh` (task #1308)

`./release_darwin.sh [--server] [--mac] [--ios]` writes to `dist/`; see its
header for the environment it reads, and
[decision 1268](../decisions/1268-release-darwin.md). `release.yml` runs the
same script. A local `--ios` run with an API key **uploads to TestFlight**.

## Verification

`scripts/exit/s1278.sh` checks the scripts' syntax, the workflow's gates, the
bundle id, and dry-runs an install from a stand-in tarball layout.

Run by hand during development (macOS 15, no signing):
`./release_darwin.sh --server --unsigned` built a universal binary, and the
extracted tarball's `bin/Run` started and loaded the compatibility dylib from
beside itself. The universal build has no `@loader_path` rpath, so the payload
step adds one.

**Not run:** Developer ID signing, notarization, the Mac and iOS targets, the
workflow itself, and an install on a clean Mac. A `workflow_dispatch` run is the
test for those.
