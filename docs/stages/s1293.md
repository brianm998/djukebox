# s1293: AsyncAudioPlayer tests keep their TrackFetcher alive (task #1322)

`AsyncAudioPlayerTests.makePlayer` let its `TrackFetcher` deallocate on return,
because `AsyncAudioPlayer` and `HistoryFetcher` reference it weakly by design.
Track lookups then found nothing, and tests such as
`pendingIndexesSkipTheQueueHeadWhenNothingIsPlaying()` failed.

The same fix landed first through s1290 (`FakeAudioPlayer.retainedFetcher`) and
s1292 (`withExtendedLifetime`). This task keeps that code and adds no test code
of its own, only this note, decision 1283 and its exit script.

## Verification

`swift test --package-path DJukeboxClient`, or `scripts/exit/s1293.sh` for
`AsyncAudioPlayerTests` alone.
